# Smart Food Donation Platform

Smart Food Donation Platform is a full-stack MERN application designed to reduce food waste by connecting food donors (restaurants, hotels, individuals, and organizations) with NGOs and food receivers.

The platform enables donors to list surplus food, allows NGOs to request and manage pickups, and provides administrators with tools to monitor platform activities. It includes secure JWT authentication, role-based access control, RESTful APIs, and a responsive React frontend.

## 🚀 Features

- 🔐 JWT Authentication & Authorization
- 👤 Role-Based Access (Admin, Donor, Receiver)
- 🍱 Food Donation Listings
- 📍 Pickup Request & Tracking
- 📦 Donation Status Management
- 📊 Admin Dashboard
- 📱 Responsive UI
- 🌐 REST API Architecture

## 🛠 Tech Stack

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
- API: REST API
